# Brand Identity – Teaching App

## Essence
- **Tagline:** "Teaching, Elevated."
- **Promise:** Evidence-based, calm, modern tool that helps professors design better lectures & activities.

## Personality
- Scholarly, not stuffy
- Calm, minimal, intelligent
- Collegial, human, non-gimmicky
- Unobtrusive yet powerful

## Visual Direction
- **Layout:** lots of white space, clear hierarchy, low visual noise.
- **Components:** cards, subtle dividers, minimal borders, rounded corners, gentle shadows.

## Colors (Calm Academic)
- **Primary:** Deep navy `#0A1A2A`
- **Accent:** Muted gold `#C6A667`
- **Background:** Soft gray `#F1F3F5`
- **Text:** Slate `#4B5563`

## Typography
- **Headings:** Inter (or similar modern sans)
- **Body:** Inter / Source Serif 4
- **Code/math:** JetBrains Mono (if needed)

## Copy Tone
- Clear, concise, collegial
- Avoid hype, jargon, and cutesy language
- Sounds like a good teaching center: "Here are three evidence-based ways to…"

## Implementation Guidelines

### Color Usage
- Use `brand-navy` for primary actions, headers, and navigation
- Use `brand-gold` sparingly for accents, highlights, and key CTAs
- Use `brand-bg` for page backgrounds and subtle containers
- Use `brand-text` for body text and secondary elements

### Spacing
- Generous margins between sections (8rem minimum)
- Card padding should be at least 1.5rem (6)
- Button padding: horizontal 2rem (8), vertical 1rem (4)

### Typography Hierarchy
```
h1: 3xl (Inter, bold, brand-navy)
h2: 2xl (Inter, semibold, brand-navy)
h3: xl (Inter, medium, brand-navy)
body: base (Inter, normal, brand-text)
caption: sm (Inter, normal, slate-500)
```

### Components
- **Cards:** rounded-2xl, shadow-card, bg-white, p-6
- **Buttons:** rounded-xl, clear hierarchy (primary vs secondary)
- **Inputs:** rounded-lg, subtle borders, focus states with brand-gold
- **Badges:** rounded-full, minimal colors

### Accessibility
- Minimum contrast ratio 4.5:1 for normal text
- Minimum contrast ratio 3:1 for large text
- All interactive elements keyboard accessible
- Clear focus indicators

### Copy Guidelines
- Use active voice
- Be specific and actionable
- Avoid marketing buzzwords ("revolutionary", "game-changing", etc.)
- Prefer "evidence-based" over "AI-powered"
- Sound like a colleague, not a salesperson

### Examples of Good Copy
✅ "Generate learning outcomes aligned with Bloom's taxonomy"
✅ "Analyze your syllabus for workload balance and coverage gaps"
✅ "Create exercises that measure specific cognitive levels"

### Examples of Bad Copy
❌ "AI magic that transforms your teaching!"
❌ "Revolutionary game-changing platform!"
❌ "Unlock the power of next-gen pedagogy!"
